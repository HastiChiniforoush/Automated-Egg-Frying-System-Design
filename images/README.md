# Project Images and Diagrams

Use this folder for visual evidence from the **2026 design project**:

- Overall system concept sketch or CAD render
- Electrical or functional block diagram
- Sensor interface diagram
- Electrical schematic exports (if owned and permitted to publish)
- Annotated component-selection illustrations

Recommended filenames: `system-concept.png`, `electrical-block-diagram.png`, `sensor-interfaces.png`.

**Attribution:** Some drawings in the group report were created by teammates. Publish them only with the necessary permission and label them as *concepts/design visualizations*, not photographs of a built machine.

No images are included in this starter package: add the actual approved figures later and link them in the top-level README.
